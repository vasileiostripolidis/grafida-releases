# DOC — Λήψεις

Ελαφρύς επεξεργαστής κειμένου για Windows, συμβατός με αρχεία `.docx`.

**[⬇ Κατέβασε την τελευταία έκδοση](https://github.com/vasileiostripolidis/grafida-releases/releases/latest)** — άνοιξε το αρχείο `…-setup.exe`.

Η εφαρμογή ενημερώνεται αυτόματα (προεπιλογή: κάθε 1η του μήνα — αλλάζει από *Αρχείο → Ρυθμίσεις*).

---
Το DOC δεν σχετίζεται με τη Microsoft. Το «Word» είναι εμπορικό σήμα της Microsoft Corporation.
